# 📊 Retail Demand Forecasting Dashboard

## 📌 Overview

This project is a **Retail Demand Forecasting Dashboard** developed using Python and Streamlit.
It helps analyze retail sales data and visualize demand trends to support better decision-making.

---

## 🚀 Features

* 📈 Interactive dashboard for data visualization
* 📊 Demand trend analysis
* 📁 CSV-based data processing
* ⚡ Simple and user-friendly interface

---

## 🛠️ Tech Stack

* Python
* Streamlit
* Pandas
* Matplotlib / Plotly

---

## ⚙️ How to Run

1. Install dependencies:

```
pip install -r requirements.txt
```

2. Run the dashboard:

```
streamlit run streamlit_dashboard.py
```
